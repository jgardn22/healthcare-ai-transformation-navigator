Choose the simplest fit

Match the approach to the outcome

These five patterns describe ways of working, not a maturity ladder. Use the decision path first, then hover or tap a pattern to explore it.

Decision path: stop when the requirement is met
  1. Help with everyday work: start with Microsoft 365 Copilot for drafting, summarizing, analysis and finding information.
  2. A reviewed multi-step deliverable: consider Copilot Cowork when a person can delegate a defined task and check the result.
  3. Repeatable knowledge questions: use Agent Builder or SharePoint agents over approved content. External-service actions require another approach.
  4. Known steps or structured intake: use Power Automate and Power Apps. A deterministic workflow may not need AI.
  5. Conversation plus configured actions: consider Copilot Studio if simpler options cannot meet the requirement. Start with one agent.
  6. Custom engineering requirements: consider Foundry or pro-code for logic, integration or model needs the earlier options cannot meet.
  7. A requirement that needs both: use a hybrid only when a specific boundary or integration calls for it.

Define the outcome, approved data, action boundary, exception owner and success measure first. Read the advisor reference.
